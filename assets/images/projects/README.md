## 📐 Recommended Specs

### Image Size
- **Width**: 1080px - 1440px
- **Height**: 1920px - 2400px
- **Aspect Ratio**: 9:16 (mobile portrait)

### File Format
- ✅ PNG (recommended for UI)
- ✅ JPG (for photos)
- ✅ WebP (best compression)

### File Size
- Target: < 500KB per image
- Use compression tools if larger

## 🛠️ How to Take Screenshots

### From Your Apps:

#### Android:
1. Run app on Android device/emulator
2. Navigate to the screen
3. Press **Power + Volume Down**
4. Find in Gallery/Screenshots folder

#### iOS:
1. Run app on iOS device/simulator
2. Navigate to the screen
3. Press **Power + Volume Up** (or **Home + Power** on older devices)
4. Find in Photos app

#### Emulator/Simulator:
- **Android Studio**: Camera icon or Ctrl+S
- **Xcode Simulator**: File > Save Screen

## 🎨 Image Optimization

### Online Tools (Free):
1. **TinyPNG** - https://tinypng.com/
   - Excellent compression
   - Maintains quality
   - Batch processing

2. **Squoosh** - https://squoosh.app/
   - Google's tool
   - Real-time preview
   - Multiple formats

3. **CompressJPEG** - https://compressjpeg.com/
   - Simple interface
   - Good for JPG

### Tips:
- Compress to ~300-500KB
- Maintain visual quality
- Test on portfolio site
- Use WebP if possible
