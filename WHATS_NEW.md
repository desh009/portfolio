## 🎨 Animation Timeline

```
Page Load:
├─ 0ms: Page loads
├─ 200ms: "Hi, I'm" fades in
├─ 400ms: Name with shimmer appears
├─ 600ms: Role title fades in
├─ 800ms: About text appears
├─ 1000ms: CTA buttons slide in
├─ 1200ms: Social icons appear
└─ 1400ms: Scroll indicator animates

Scroll:
├─ Section enters viewport
├─ Fade + slide animation
├─ Staggered items reveal
└─ Continuous on scroll

Hover:
├─ Mouse enter
├─ Scale increases (200ms)
├─ Glow appears
├─ 3D tilt (card specific)
└─ Smooth exit on mouse leave
```

## 🎨 Customization

All animations are customizable:
- Duration
- Delay
- Curve
- Distance
- Scale
- Colors
- Enable/disable

Example:
```dart
FloatingAnimation(
  duration: Duration(seconds: 4),
  distance: 20,
  child: YourWidget(),
)
```
